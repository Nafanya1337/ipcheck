# ipcheck

[English](README.md) | [Русский](README.ru.md)

Консольный скрипт, который оценивает IPv4-адрес сервера перед покупкой VPS или выделенного сервера. Вставляете IP, получаете карту маршрута, сравнение геобаз и DNS-резолверов, проверку блокировок и итоговый балл от 0 до 100.

Сделан для задачи "подобрать европейскую локацию с минимальным пингом из России", но подходит для оценки любого IP.

## Что проверяет

| Метрика | Что измеряется | Вес |
|---|---|---|
| Пинг | средний RTT по mtr (30 пакетов) | 18 |
| Потери | потери на последнем хопе | 12 |
| Джиттер | StDev по mtr | 6 |
| TCP | время подключения к портам 443, 80, 22 | 6 |
| Маршрут | число хопов до цели | 5 |
| PTR | reverse DNS у 5 резолверов (системный, Cloudflare, Google, Quad9, Yandex) | 5 |
| Локация / AS | страна и AS по большинству геобаз | 8 |
| Согласие гео-баз | совпадение страны в 5 сервисах | 10 |
| Спам-списки | Spamhaus, SpamCop, Barracuda, UCEPROTECT | 5 |
| Блокировки РКН | cheburcheck.ru, antifilter, списки CDN | 25 |

Если IP найден в блокировках, итоговый балл ограничивается 40.

Отчёт состоит из четырёх блоков: карта пути пакета с ASN каждого хопа и границами между AS, таблица ответов пяти геосервисов (ip-api, ipinfo, ipwho.is, ipapi.co, geojs), таблица PTR по резолверам и итоговая таблица с баллами.

## Требования

Python 3.8+ и права root. Внешних Python-библиотек нет. Скрипт сам запросит sudo и установит mtr через apt, dnf, yum, apk, pacman, zypper или brew.

## Использование

```bash
git clone https://github.com/Nafanya1337/ipcheck.git
cd ipcheck
python3 check.py
```

Дальше вставьте IP. Можно передать адреса аргументами, тогда в конце будет сравнительный рейтинг:

```bash
python3 check.py 195.123.209.202 185.237.185.52 92.118.205.95
```

Флаг `--debug` печатает текст, который вернул cheburcheck.ru. Он нужен, чтобы подправить разбор страницы, если сервис изменит вёрстку.

Для честного результата запускайте скрипт с той машины, откуда пойдёт трафик, например с вашей российской релейной ноды, а не с домашнего интернета. Лучше замерить с нескольких точек и в разное время суток.

## Настройка

Веса метрик лежат в словаре `W` в начале файла, пороги пинга, потерь и джиттера в `LAT`, `LOSS`, `JIT`. Лимит балла для заблокированных адресов задаёт `BLOCKED_CAP`.

## Как работает проверка блокировок

У cheburcheck.ru нет JSON API, скрипт запрашивает страницу `/check?target=IP` и разбирает видимый текст по ключевым фразам. Параллельно IP сверяется с открытыми списками antifilter.download и cdn-ip-ranges, которые кешируются на 6 часов в `/tmp/ipcheck-cache`. Если источники расходятся, метрика получает 50 баллов и пометку "расхождение".

## Приватность

Проверяемый IP отправляется во внешние сервисы: ip-api.com, ipinfo.io, ipwho.is, ipapi.co, geojs.io и cheburcheck.ru (он сохраняет запросы у себя). Ваш внешний IP и IP хопов маршрута уходят на ip-api.com. Публичные DNS-резолверы получают PTR-запросы. Учитывайте это, если проверяете адреса, которые не хотите светить.

## Ограничения

Только IPv4. Бесплатные API имеют лимиты, при частых запусках часть ASN или гео-данных может не прийти. Метрики, которые не удалось измерить, помечаются n/a и не входят в итог. Скрипт даёт оценку, а не гарантию, окончательное решение лучше подтверждать пробным тарифом.
